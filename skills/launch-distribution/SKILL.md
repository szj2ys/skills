# Launch Distribution

## The one rule

**Go where the target user already asks for this, give something useful there, and count what each channel brings.** A post that gives that community nothing is spam.

## Mode

Research, channel choice and drafts need no permission. Posting, commenting, messaging and account creation happen only within the user's authorization for that channel and account; without it, deliver the drafts. Paid promotion needs a budget approval.

## 1. Find where users ask

Start from the buyer and how competitors acquire users. Search for the problem, in the buyer's words, in the communities they use (Reddit, Hacker News, Indie Hackers, V2EX, 小红书, 即刻, X, Discord and Slack groups, niche forums, YouTube comments). Record each thread where someone asks for this: link, date, engagement. Read each community's self-promotion rules; incompatible channels are out.

## 2. Choose up to three experiments

Rank by audience fit and evidence of people asking; effort and cost count against a channel. Zero qualifying channels is a valid answer. Use a launch platform (Product Hunt, Show HN) only when a stranger can complete the core task end to end. Each experiment states its time or money cap, its target, and its stop rule.

## 3. Write per channel

Native format and tone: a useful answer, a build story, a tool shared where it is relevant. Lead with the problem and the result, disclose that you made it, and use only claims the product supports. Different text for each channel.

## 4. Measure

Give each post its own UTM link where the channel allows links; otherwise use native metrics and referrers. Before posting, open the link logged out on a phone with a test identity, complete the core task in a sandbox, and see the visit attributed in analytics. Afterwards read visits, signups, first value and payments per channel.

## 5. Ledger

Record each post in the `backlink-outreach` ledger (`backlinks-ledger.csv` or the project's outreach ledger) using its columns: channel as `site`, the thread or submit page as `submit_page`, account and authorization in `note`. A timed-out post is checked on the site before retrying.

## Output

Channel table (channel | threads found | rules | fit | chosen?) · drafts for chosen channels with their tracking links · preflight results · a 14-day plan with the number that decides continue or stop per channel and who answers replies.
