# Stage 2 · 金句梳理法

**输入**：Stage 1 的素材卡 + 一念判定 + 读者卡。
**输出**：一张金句候选表（5–8 条），其中 1 条被选为收口句、1–2 条埋在文中。

金句不是写完稿子再"升华"出来的，是**在动笔前先挖出来**的。先有金句，后有稿子——这是罗胖体和普通自媒体的分水岭。

---

## 零、金句的三个来源（不止用户素材）

| 优先级 | 来源 | 里面有什么 | 怎么用 |
|---|---|---|---|
| 1 | **用户素材** | 亲历的话、书摘里的原句 | 首选——自带真实感，最贴读者卡 |
| 2 | **名言库** `~/Documents/githubprojects/quotes/public/quotes.json`（约 5400 条中文名言，{quote, author}） | 名人现成金句，短、有反转的居多 | 借人句式的首选弹药库 |
| 3 | **书库** `~/Downloads/reading/epub-md`（约 4500 本书的 md 全文） | 书里的结论句、判断句 | 找"某本书里有个说法"——书/文章锚 + 借人句式 |

用脚本一次性**召回**两个库：

```bash
python3 scripts/search_quotes.py "关键词1 关键词2" [--source both|quotes|books] [--lang both|zh|en] [--max 12]
```

- 关键词从**一念判定 + 读者卡的语言**里取（读者用什么词，就查什么词），一般 2–3 个，可跑 2–3 轮换词。
- **`--lang zh` 只要中文原句**（可直接引用）；**`--lang en` 只要英文**（只能转述）。默认 both。
- 书库单趟扫描约 20 秒（ripgrep），耐心的活，一次 S2 最多跑 2–3 轮，别刷屏。

### ⚠️ 召回 ≠ 可用：脚本只会捞，不会挑

脚本按关键词捞句子，**没有"这是不是金句"的判断力**。实测查"坚持 长期"会召回：

- 一段庞氏骗局小说里的人物对话（叙事句，不是金句）
- `—— asking · quotes.json` 这种作者元数据噪声
- "人的信用是自己坚持出来的" / "一个人的信用是你自己坚持出来的"（近似重复，脚本没去干净）

所以脚本输出是 **raw 候选**。下一步**派 quote-miner subagent**（`agents/quote-miner.md`）甄别：它负责过四条硬标准、剔除噪声、近似去重、复核出处，只返回 ≤3 条真正可用的。

**自己筛也行**，但必须逐条过下文四条硬标准，且遵守下面第 3 条"出处宁缺毋滥"。

### 引用保真（借人句式的铁律）

1. **中文原句逐字引用**，标"—— 作者"；不许改写后冒充原句。
2. **英文原句只转述**："《书名》里有个说法，大意是……"，注明作者；稿子是中文，逐字夹英文会破坏贴耳感（除非原句极短且是名句）。
3. **出处宁缺毋滥**：脚本给的作者/书名要自己复核一眼（书库元数据有噪声）；查不到出处的句子宁可不借。
4. **数量上限**：一篇稿子外部借来的金句 ≤ 1–2 条，主体必须是用户素材里长出来的——借太多就成名言拼盘，人味没了。

## 一、五种金句型（全部来自语料实测）

| 型 | 公式 | 语料实例 |
|---|---|---|
| **重定义式** | 所谓 A，不是 X，而是 Y。 | 「所谓办法，就是应对外界的变量。所谓算法，就是让自己成为世界的变量。」 |
| **对照反转式** | 过去我们以为 X，其实 Y。 | 「跟着数据跑是一种策略，让数据跟着你跑，其实是一种更有效的策略。」 |
| **造词命名式** | 我们把这叫做「__」。 | 「整个行业都在等待一个时刻，我们就称之为"轴承时刻"吧。」 |
| **升维式** | 这不是 __ 问题，是 __ 问题。 | 「过去我们以为曝光是个位置问题。其实它是个证据问题。」 |
| **借人句式** | 某某跟我说过一句话："…"。 | 「最后这位导演跟我说了一句金句，他说："想有意外之喜，请先接受现状。"」 |

**优先级**：重定义式 > 对照反转式 > 升维式 > 造词命名式 > 借人句式。
借人句式是兜底——当自己的话说不圆时，把金句所有权让渡给素材里的某个人（罗胖常用，见语音2018-07-19）。

## 二、七问挖金句（对一念判定逐条问一遍）

1. **读者卡里那个他，以为的是什么？** → 得到靶子 X（靶子不是"大众以为"，是**这批读者**的现有错误认知——他认不出来，这一枪就打空）
2. **真相反过来是什么？** → 得到 Y，凑成"过去你以为 X，其实 Y"
3. **能不能用"不是…而是…"重写？** → 重定义式
4. **能不能给它起个名字？** → 造词（优先用素材里的具体名词，如"轴承时刻""杨秀清陷阱"）
5. **它属于哪一类更大的东西？** → 升维式（把具体问题抬到"位置问题/证据问题/系统问题"）
6. **素材里有没有一句现成的话能替我说？** → 借人句式
7. **去掉上下文，这句话还能不能成立？** → 可截屏测试，答否就重写

每问产出一条候选，七问下来 5–8 条，足够挑。

---

## 三、金句四条硬标准

1. **短**：≤ 30 字。超过 30 字记不住。
2. **有反转或对照**：平铺直叙的漂亮话不是金句，是标语。
3. **脱离上下文能单独成立**：遮住前后文念一遍，还能懂，才合格。
4. **打在读者卡的痛点上（心坎测试）**：把金句里的主语换成读者卡的"他"，读一遍——他会不会"这说的就是我"？替他说出了他说不出的那句，才算说到心坎里；只是"有道理"，不算。

**淘汰规则**：前两条缺一条 → 降级为"文中句"；第 3 条缺 → 重写；第 4 条缺 → 回读者卡核对痛点，或换一条候选。

---

## 四、金句在稿子里的分布

| 位置 | 用哪条 | 作用 |
|---|---|---|
| 第④拍收口（短稿） | 最强的一条，通常是重定义式 | 让人截屏带走 |
| 第③拍转折处（短稿） | 对照反转式 | 完成"你以为…其实…"的兑现 |
| 长稿每幕末尾 | 各幕一条 | 制造节奏，防止听众掉线 |
| 长稿大反转后 | 造词命名式 | 给这套系统解释起个名字，便于传播 |
| 长稿结尾 | 升维式或借人句式 | 给情绪，不给总结 |

---

## 五、反向检查：哪些不是金句

| ❌ | 为什么 |
|---|---|
| 「只有不断努力，才能成功」 | 无反转、无对照、可替代性 100% |
| 「这个时代唯一不变的就是变化」 | 陈词滥调 |
| 「让我们一起拥抱未来」 | 号召体，不是认知增量 |
| 「正如某某所说，……」（长引号抄书） | 那是引用，不是金句；引用必须压缩到 ≤30 字才算 |
