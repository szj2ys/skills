# 罗胖体风格核心（写稿时随时对照的精简版）

本文件覆盖写稿所需的全部硬规则。更细的模式库与范本在同目录：
`patterns.md`（连接词覆盖率表、开场/收尾模式库、分季演进）、`examples.md`（结构标注范本 + 反面教材）。
两个入口都要用：流水线 S4 全程对照，入口 B（改稿/查风格）以此为自检底稿。

**体量阈值单一来源**：短稿 **320–430 字**（>550 判 FAIL 并改判长稿）、长稿 **≥3000 字**（语料中位 14.8k，3000 只是下限不是目标）以 `scripts/check_draft.py` 为准；
本文件及 stage 文件如与脚本不一致，以脚本为准并回改文档。

**统计口径**：短稿基准全部来自**纯口播子集 1,657 篇**（《罗胖60秒》2,350 篇剔除 693 篇 >800 字的图书推广长文）。中位 350 字，不是 378。详见 `analysis.md` 第六节对账表。

## 一句话范式

> 用一个"我刚发现"的笨人视角，把一条反常识结论，包装成「有出处 + 有场景 + 有金句」的最小故事。

---

## 六大铁律

1. **一念贯穿** — 一篇只卖一个认知增量。
2. **具象锚开局** — 第一句必须有书名/人名/日期/场景。抽象开头判死刑。
3. **无能人设** — 不自居权威，只做转述者。「我啃了两年只敢说得其大略」。
4. **第二人称贴耳** — 写给"一个人"。短稿篇均 你 3.5 / 我 3.5 / 我们 1.2（合计 ≈ 8，脚本下限 5）。这是**密度**不是**配额**：别为了凑数硬塞"你"，一段里自然出现两三次即可。
5. **转折必显式** — 用「其实 / 但是 / 所以你看 / 你看」把那一跳喊出来。
6. **结尾给情绪，不给总结** — 绝不写"综上所述"。

---

## 对象感（所有技法的前置）

六大铁律里的人称、锚点、反转，全都打在**一个具体的人**身上。没有对象感，其余五条是空转。

- **先有人，后有稿**：动笔前必须有一张读者卡（见 `stage-0-brainstorm.md`）——画像、此刻场景、痛点、错误认知、渴望、他的语言。缺这张卡，后面全是猜。
- **靶子是他的靶子**：「你以为 X」的 X 不是"大众以为"，是**这批读者**现有的错误认知（读者卡第 4 行）。他认不出来，反转就打空。
- **场景是他的场景**：开场锚、举例、类比优先取读者世界里存在的物件和处境——他看到"和我一样的人"才读下去。
- **语言是他的语言**：用他会用的词，不用行业黑话；预置反驳（"你可能会说…"）要说他真会抬的那句杠。
- **金句要过心坎测试**：主语换成"他"读一遍——"这说的就是我"才算数；只是"有道理"，重写。
- **闭卷测试**：遮住读者卡读成稿，如果还能准确说出"这是写给谁的、他愁什么"，对象感才合格。

## 转折词库（按功能取用）

- **反转锤**：其实 / 但是 / 可是 / 不过 / 然而 / 实际上 / 真相是
- **拉视线**：你看 / 你想 / 你发现没有 / 请注意
- **抽结论**：所以你看 / 说白了 / 换句话说 / 这就说到
- **重启故事**：话说 / 话说有一天 / 回到… / 说到这儿
- **预置反驳**：你可能会问 / 你可能会说 / 那位说了 / 有人说
- **举证据**：给大家举个例子 / 比方说 / 有一本书叫《…》
- **口语粒子**：嘛、呢、吧、啊、对吧、是吧、那好、说白了

---

## 造词公式

- `所谓 A，不是 X，而是 Y。`
- `A 的本质不是 X，是 Y。`
- `我们就称之为「__」吧。`
- `这不是 __ 问题，是 __ 问题。`

优先用素材里的具体名词造词（"轴承时刻""杨秀清陷阱"），避免抽象生造。

## 覆盖率的实测参考（决定是否"够味"）

长稿 194 篇：其实/但是/所以/不是 **100%**，为什么 99%，你看/这就是 98%，回到 93%，所以你看 87%，对吧 86%，说白了 71%，话说 64%，你以为 49%。
短稿 2350 篇：但是 61%、不是 61%、你看 54%、所以 53%、其实 51%、为什么 31%、话说 16%、注意 11%、**你以为 仅 1%**。

**关键差异**：短稿几乎不用「你以为」，改用「其实/但是」做微反转；长稿「你以为…其实…」是标配。

## 取哪一期的 60 秒？（模板的来源说明）

四个模板用的是**后期成熟体**（2018–2020），不是 2012 年的早期散文体。三个时期骨架一致、皮相不同，按你的场景选：

| 时期 | 皮相 | 特征 | 什么时候用 |
|---|---|---|---|
| 早期（2012–16） | 散文体 | 无编号、无标题问句，助词密度高（哈/啊/呢/嘛） | 要"随笔感"、不想编号时 |
| 中期（2017–18） | 过渡 | 编号开始出现，标题问句 51% | — |
| **后期（2019–20）** | **编号体** | 显式 `1./2./3./4.` 四拍；**标题即问句占 93–94%** | **默认。模板取的就是这一期** |

早期与后期的差别在**标记层**（编号、标题问句、助词），**不在骨架层**——四拍（锚→铺→转→收）三期完全相同。所以：想要编号就编号，不想要就不编号，但**四拍一拍都不能少**。

## 绝对不要出现

- 「罗胖曰」等古风落款（全语料 0 次，后人误传）
- 「综上所述 / 总之 / 以上就是 / 让我们一起 / 众所周知」
- 「随着…的发展 / 在当今…时代」式抽象开场
- 学术引用体（"根据研究表明"）→ 改成"我最近读到一本书，书里说…"
- 自居权威（"我认为 / 我坚信"）→ 改成"书里的说法让我大吃一惊…"
