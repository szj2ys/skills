### 短稿（2350 篇《罗胖60秒》全库统计）

> **口径先行**：2,350 篇里 693 篇（29%）是 >800 字的图书推广长文（中位 2,310）。
> **体量、人称、问号三项基准一律取「纯口播子集 1,657 篇」**；只有"覆盖率"这类词频统计用全库。

- **纯口播子集 1,657 篇**：p25 335 / 中位 **350** / p75 386 / max 788 字
- 49%（1,156 篇）显式使用编号四拍（语料中写作转义形式 `1\.`）
- 覆盖率（全库）：但是 61%、不是 61%、你看 54%、所以 53%、其实 51%、为什么 31%、话说 16%、注意 11%、**你以为 仅 1%**
- 篇均人称（纯口播）：你 3.5 / 我 3.5 / 我们 1.2；问号平均 1.68 个/篇
- 末 80 字含：你看 562 篇、问号结尾 412 篇、"下一页"CTA 325 篇、所以 308、其实 222、推荐 174、"啊"收尾 164
- 开头 60 字内：含"有"682 篇、最近 346、我 330、昨天 310、今天 198、话说 194

> **关键差异**：短稿几乎不用「你以为」（1%），改用「其实/但是」做微反转；长稿「你以为…其实…」是标配（49%）。短稿靠编号四拍，长稿靠"回到/话说"串幕。
>
> **别把推广长文当短稿样本**：那 693 篇是"60 秒栏目里塞的图书推介"，不是口播稿。拿它们的长度（中位 2,310）当短稿基准，会写出比 3/4 的原版还长的"60 秒稿"。

## 二、开场模式库

### 短稿（四型）

| 型 | 模板 | 原文例 |
|---|---|---|
| 来源锚 | 昨天我在《…》里看到 / 最近一位…跟我讲 | 「昨天，我在《李翔知识内参》里看到，日本家居行业巨头尼达利有一个规定…」 |
| 时间锚 | 话说 + 具体日期/年份 | 「话说巴黎和会开到最后，在对合约做表决的那一天…」 |
| 场景锚 | 具体职业/现场的一个反常细节 | 「话说，在电影或者电视的拍摄现场，经常会遇到一种情况…」 |
| 设问锚 | 标题即问句，正文首句复述 | 「为什么是轴承？」（后期 2019–20 年占 93%） |

### 长稿（六型）

| 型 | 原文例 |
|---|---|
| 迎客句 + 承接前作 | 「我们这一季的视频节目，谈到日本帝国的兴衰已经有三期了」 |
| 迎客句 + 抛人物 | 「我们今天跟大家聊一个牛人，真的是牛人，就是牛顿」 |
| 认怂 / 认难 | 「今天我们要说的这个话题，我真的是犹豫了很久，好难好难哪」 |
| 坦白私心（反信任术） | 「今天整个节目就是一个大广告，卖的是啥？就是我手边的这一套书」 |
| 标题党自白 | 「这我承认有点标题党，是虚晃一枪…其实我谈的是学习的真相」 |
| 历史现场 | 「话说公元 1644 年的 4 月 22 号的晚上，紫禁城已经在一片黑暗之中」 |

另有口号式：「死磕自己，愉悦大家，欢迎来到我们的罗辑思维！」（第二季出现 10 次）。

## 三、收尾模式库

### 短稿
1. **重定义金句**（最多）：「所谓办法，就是应对外界的变量。所谓算法，就是让自己成为世界的变量。」
2. **对照反转收**：「过去我们总是主张，做经营应该跟着数据决策。但是，跟着数据跑是一种策略，让数据跟着你跑，其实是一种更有效的策略。」
3. **感叹收**：「天底下哪有这么好的职业啊。」
4. **反问收**（仅 2%）：「你选择哪个呢？」
5. **CTA 收**（推广期）：「推荐给你。」／「今天您点击'下一页'，给你看篇文章。」

### 长稿
1. **态度升华**：「我们今天这个有选择的时代，真好！」
2. **名人金句盖章**：陀思妥耶夫斯基、罗素、格雷…收在别人的话上
3. **留钩子（连载）**：「今天留个尾巴，我们下期来讲」
4. **荐书 CTA**：「节目的最后还是做个广告…」
5. **三点归结**：「关于大数据和隐私，我们就归结三句话，第一句…第二…第三…」
6. **自指收**：「我们也只是你生命中那弱水三千当中的一小瓢」

**共同点**：从不 recap 论点。收尾是情绪，不是结论。

## 四、反转模板（核心发生器）

### 长稿：你以为…其实…
```
[抛大众共识] 你以为 X？/ 很多人认为 X / 大家都觉得 X
[锤子词]     其实 / 不是 / 错 / 非也 / 不见得 / NO
[真相]       Y（结构性解释）
```
实例：
- 「你以为达尔文是你们家死去的老头呢，达尔文是国家的宝贝」
- 「你以为管仲只有这一面吗？NO。」
- 「过去我们都以为权力就是予取予求…其实正好相反，集权是调动大多数人心底的恶来巩固自己的系统。」
- 「你以为你在驯养植物、驯养动物，实际上你也在被驯养」
- 「你以为多元化是企业主动的，他是没办法」

### 反转的深层规律
**被打败的永远是"个人道德判断"，翻出的永远是"制度/系统/结构逻辑"。**
奸臣、卖国贼、剩女、慈善之恶、秦亡、甲午——全部从"人品/道德"重解成"结构/激励/约束"。
这是罗胖立场统一性的真正来源，也是"去道德化"这一招的可复制内核。

### 短稿：其实微反转
短稿不喊"你以为"，而是把常识说完，紧跟一句「其实/但是/但是你发现没有」再翻。
- 「这个说法其实不像表面看上去那么简单，好像有盼头，心情就好，所以身体就好。不是。」
- 「这个做法听起来很奇怪。难道不应该是把卖得不好的产品先更新掉吗？为什么反其道而行之呢？你琢磨琢磨它的道理哈。」

## 五、虚拟对话者（节奏引擎）

用 `那位说了 / 有人说 / 你可能会问 / 那你会问了 / 你可能会反驳` 凭空造一个对手，先替听众把异议说出来再击破。与"你以为"反转配套，让独白听起来像双人辩论。

实例：
- 「你可能会说罗胖又要没底线没节操，替汉奸卖国贼翻案吗？还真不是」
- 「有朋友就说，啥叫原本应该有的样子？难道什么事都有应该的样子吗？谁规定的应该？」
- 「你可能会反驳…」（第四季密集出现）

## 六、无能人设（权威引擎）

**信任 = 自黑 + 转述权威，绝不自居权威。**

- 「罗胖也不懂什么物理」「罗胖也很愚钝」「文科生」
- 「我啃了两年之久，只敢说是得其大略」
- 「我当时像一个粉丝一样表达了各种倾慕之情」
- 「我抱着追星的心态请他吃了一顿饭」
- 「给大家念一下，我实在背不下来了」

配套：**所有反转都不是从权威口吻抛出，而是"我原来也这么想，结果书里说…"**。

### 跨年演讲（舞台体，与棚内集根本不同）
- 开场签名换掉：「欢迎各位时间的朋友，你看这是四十年前的我」
- 个人脆弱故事起头（缆车失恋）+ 「发下一个大愿，我要做二十年的跨年演讲」
- 宏观结构 = 编号话题串（约 7 个），每个话题：轶事/数据 → 大佬八卦 → 时间/生物视角重框 → 金句结论
- 4 小时弧线靠四根 glue：① "时间的朋友"复诵当节拍器 ② 贯穿隐喻（生物学思维/时间尺度）③ 每段自含、随时重新锚定 ④ "我们"共在感 + 自曝创业一年
- 收尾不推单书、不"下期接着说"，改为向前祝福式收束

## 八、广告即内容（商业动机前置）

罗胖从不藏商业目的，反而**把私心写在脸上当信任状**：
- 「今天整个节目就是一个大广告」
- 「奸商嘴脸又出来了」
- 「说罗胖搞的那个《罗辑思维》，其实就是个生意，是个奸商，就是为了挣钱，怎地？」
- 「这我承认有点标题党，是虚晃一枪」

可迁移：**先坦白你的动机，读者反而卸下防备；随后产品被当成"本集逻辑的自然兑现"，而不是插播广告。**
