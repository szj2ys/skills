# Stage 3 · 大纲法

**输入**：Stage 1 素材卡 + Stage 2 金句表。
**输出**：一张拍卡 / 段卡。
**⚠️ 这是全流程唯一的人工闸门**：大纲写完后必须展示给用户，等确认再进 Stage 4。

---

## 一、短稿大纲（四拍卡）

四拍的靶子、场景、语言全部取自读者卡——**每一拍都问一句"他此刻会不会这样"**。

| 拍 | 任务 | 字数 | 素材来源 | 检查点 |
|---|---|---|---|---|
| **① 锚** | 把话题钉在一个可核验的具象上 | 70–110 | 事实/数据锚、书锚、引语锚、场景锚 | 最好选**读者世界里也有**的锚；有没有书名号/年份/人名/一句原话？ |
| **② 铺** | 替读者把显而易见的答案说出来 | 60–100 | 读者卡的"错误认知" = 靶子 X | 他会不会点头："对，我就是这么想的"？ |
| **③ 转** | 用「其实/但是」翻出机制 | 90–140 | 反常识点 + 引语锚 | 翻的是不是**机制/结构**，而不只是"另一个观点"？能不能解他的痛点？ |
| **④ 收** | 「你看，」+ 金句 | 50–90 | Stage 2 收口句 | 过没过心坎测试？能不能脱离上下文单独成立？ |

**总长 320–430 字**（纯口播语料 p25 335 / 中位 350 / p75 386）。写超 550 字会被脚本判 FAIL——那说明素材量已经超出四拍承载，应改判长稿。

### 短稿大纲模板

```markdown
# 一念
我想让<读者卡的他>相信：<一句话>

# 体裁：短稿（60秒四拍）

# ① 锚（~90字）
素材：#<素材卡编号>
写法：<昨天/最近/话说/今天 + 具体来源；优先取读者卡场景里的物件/处境>
要点：<一句话>

# ② 铺（~80字）
他现在以为：<靶子 X = 读者卡第 4 行>
铺垫角度：<用他的语言、他的场景复述这个想法>

# ③ 转（~120字）
其实：<机制 Y>
怎么解他的痛点：<对应读者卡痛点第 n 条>
支撑：<素材卡编号 / 引语>
转折词：<其实 | 但是 | 可是>

# ④ 收（~70字）
收口金句：<Stage 2 选定的 #n（已过心坎测试）>

# 自检
- [ ] 只有一个念头
- [ ] 反转是从「道德/直觉判断」翻到「机制/结构」
- [ ] 有一处人味（亲历 / 认怂 / 自黑）
- [ ] 闭卷测试：遮住读者卡再读大纲，能说出这是写给谁的吗？说不出 = 对象感丢了
```

## 二、长稿大纲（五段卡）

| 段 | 任务 | 占比 | 检查点 |
|---|---|---|---|
| **报头**（可选） | 本期看点 3–5 条 bullet + 本期金句 | — | 56% 的语料有此块，先承诺价值 |
| **① 迎客 + 钩子** | 认怂 / 坦白私心 / 承接前作 / 历史现场，四选一 | 5% | 禁止抽象起手 |
| **② 多幕循环** | 3–5 幕，每幕内部：故事 → 常识解读 → 其实 → 证据 → 小金句 | 60% | 幕间用「回到…」「话说…」「说到这儿」接 |
| **③ 预置反驳** | 「你可能会问…」「那位说了…」，替读者说异议再击破 | 10% | 至少一处 |
| **④ 大反转** | 「你以为 X？其实 Y。」X = 道德判断，Y = 系统解释 | 15% | **去道德化**是长稿的灵魂 |
| **⑤ 收口** | 态度升华 / 名人金句 / 荐书 CTA / 抛回问题 | 10% | 绝不写"综上所述" |

### 长稿大纲模板

```markdown
# 一念
我想让<读者卡的他>相信：<一句话>

# 体裁：长稿（≥3000字，五段；语料中位 14.8k，3000 只是下限）

# 报头
看点：1) … 2) … 3) …   ← 看点用读者卡的语言写，让他一眼看到"这和我有关"
本期金句：…

# ① 迎客 + 钩子（~300字）
钩子类型：<认怂 / 坦白私心 / 承接前作 / 历史现场>
开场素材：#<编号>
与读者的连接：<这一钩为什么他会停下？最好取自读者卡的"此刻场景">

# ② 多幕
## 幕1：<标题>（~600字）
- 故事：#<编号>   ← 优先选与读者同处境的主角
- 常识解读：
- 其实：
- 证据：#<编号>
- 小金句：
- 对应读者痛点：#<读者卡痛点条目>

## 幕2：…
## 幕3：…

# ③ 预置反驳（~400字）
异议：「你可能会说…」   ← 用读者卡的语言说，是他真会抬的杠
击破：

# ④ 大反转（~600字）
你以为：<道德判断 X = 读者卡的错误认知>
其实：<系统解释 Y>

# ⑤ 收口（~300字）
类型：<态度升华 / 名人金句 / 荐书CTA / 抛回问题>
收口金句：#<Stage 2 编号（已过心坎测试）>

# 自检
- [ ] 每幕都自带一个钩，防止听众掉线
- [ ] 反转翻的是结构不是观点
- [ ] 至少一处造词或重定义
- [ ] 至少两处自黑/认怂
- [ ] 每一幕都能对应读者卡的一条痛点；对不上的幕要么改要么删
- [ ] 闭卷测试：遮住读者卡再读大纲，能说出这是写给谁的吗？说不出 = 对象感丢了

## 三、舞台体大纲（演讲 / 跨年式）

跨年演讲是**第三种体裁**，与棚内长稿根本不同：不是"一篇稿子"，是**若干自含话题串成的一条 4 小时弧线**。

| 段 | 任务 | 检查点 |
|---|---|---|
| **① 脆弱起头 + 发大愿** | 个人脆弱故事 → 一句大愿（"我要做二十年的跨年演讲"） | 开场签名换掉迎客句；先示弱再立信 |
| **② 编号话题串（约 7 个）** | 每话题：轶事/数据 → 大佬八卦 → **时间/生物视角重框** → 金句结论 | 每段自含、随时可重新锚定；听众中途进来也跟得上 |
| **③ glue（贯穿全篇）** | ① 一句复诵当节拍器 ② 一个贯穿隐喻 ③ "我们"共在感 ④ 自曝这一年 | 缺一根 glue，4 小时就散成 7 个短视频 |
| **④ 祝福式收束** | 向前祝福，**不推单书、不留"下期接着说"钩子** | 与长稿 CTA 收口相反 |

**与长稿的三处硬区别**：迎客句换成脆弱故事 + 大愿；收口不卖书；靠 glue 而不是靠"回到/话说"串场。走舞台体时就用这张卡，不要套五段卡。

---

## 四、向用户展示大纲（闸门）

展示时**只给大纲，不给成稿**，并附三个可选调整方向，让用户一句话就能改：

1. **换钩**：第①拍的锚可以换成 <备选锚>
2. **换核**：一念可以改成 <备选反常识点>
3. **换收**：收口金句可以换成 <Stage 2 候选 #n>

用户说"可以/继续/就这么写" → 进 Stage 4。
用户提出修改 → 改对应卡位，重新展示一次（最多两轮，避免无限来回）。

---

## 五、体裁改判

若大纲阶段发现素材量超出短稿承载（四拍塞不下，需要 3 幕以上才能说清），**即时改判为长稿**并在大纲里说明；反之亦然。改判必须告知用户，不能默默执行。

**舞台体的改判触发点**：用户明确说"演讲/发言/年会/开场致辞"，或受众是**现场一群人**（不是手机前一个人）。这时别自动走短稿——短稿是贴耳私聊体，放到台上会软。
