# Stage 1 · 素材梳理法

**输入**：S0 选题卡 + 原始素材（可能是链接、书摘、笔记、一段口述、一堆零散想法、一篇长文）。
**输出**：一张素材卡表 + 一句"一念判定" + 体裁判定。
**开工动作**：建立工作目录 `./.luopang-run/<选题短名>/`，后续所有中间产物落盘于此。

## 零、素材预处理（先于分类）

- **URL**：先抓取正文（正文抽取，剥掉导航/广告/评论），拿到纯文本再进分类；抓取失败就向用户要原文或截图，不要拿网页残片硬分。
- **本地文件 / 粘贴文本**：直接进分类。
- **口述 / 录音转写**：先按话题切成段，再去掉口语冗余，保留原话里带情绪的句子（它们是现成的引语锚）。
- **零散想法 / 关键词**：先和用户确认理解，再进入分类；不确定的猜测标注"待确认"。

---

## 一、素材六分类（逐条打标签）

| 类型 | 识别特征 | 在稿子里的位置 |
|---|---|---|
| **事实/数据锚** | 年份、金额、比例、报告名、公司名 | 第①拍（锚） |
| **引语锚** | 某人说的一句原话（带引号） | 第①拍或第③拍（当权威外包） |
| **书/文章锚** | 书名号《》+ 一句可搬运的结论 | 第①拍（最常见） |
| **场景/轶事锚** | 一个具体发生的事，有时间和人物 | 第①拍或主体某一幕 |
| **反常识点** | "大众以为 X，其实是 Y"的雏形 | 第③拍（转） |
| **亲历** | 用户自己的经历/观察 | 任意位置，最可信 |

**打标签的操作**：把素材切成最小颗粒（一条一个信息点），逐条归入上表。一条素材可以同时有两个标签，但必须选一个主标签。

---

## 二、三步筛选法

### 第 1 步：能不能支撑一个结论？
对每一条问：**"这条能证明什么？"** 答不上来的，直接丢。
素材≠信息，素材是**能当证据的东西**。罗胖从不掉无用的书袋。

### 第 2 步：找认知冲突点（这一步决定稿子成不成立）
逐条问：**"这条和大众直觉相反吗？"**

- 全部都不反 → 这篇没有稿子，只有信息。要么换角度，要么坦白告诉用户"素材目前撑不起一篇罗胖体，需要补一条 X"。
- 有一条反 → 那就是**核**，整篇围绕它。
- 有多条反 → 挑最反的那条，其余的降级为配角。**一篇只准一个核。**

### 第 3 步：判定体裁

**优先级**：用户在 S0 显式指定的体裁（"就要一段 60 秒口播" / "写篇深度长文"）> 选题卡里的"体裁倾向" > 下表规则 > 默认短稿。规则只在前面都没给出答案时生效。

| 条件 | 体裁 |
|---|---|
| 一个反常识点，一个锚就能说清，不涉及多层因果 | **短稿**（60 秒四拍，**320–430 字**；>550 会被脚本判 FAIL） |
| 需要推翻一个大众共识，涉及制度/激励/演化等多层机制，素材 ≥5 条且跨领域 | **长稿**（**≥3000 字**，五段骨架；语料中位 14.8k，3000 只是下限） |
| 舞台 / 演讲场合（跨年演讲式） | **舞台体**（见 `stage-3-outline.md` 第三节，约 7 个编号话题） |
| 边界模糊 | **默认短稿**。短稿写透了再扩写，比长稿写崩了再救容易得多。 |

判定结果写进素材卡，S3 用它选四拍卡还是五段卡，S5 用它给 `check_draft.py --form`——全流程只判这一次，中途不摇摆。

> **为什么短稿上界收到 430**：纯口播语料 p75 只有 386 字。上界放到 470 等于允许写出比 3/4 的原版还长的"60 秒稿"。
> 真写超了不要硬压——改判长稿反而对劲。

## 三、素材缺口补救表

| 缺什么 | 表现 | 怎么办 |
|---|---|---|
| 缺锚 | 开场只能说抽象概念 | 回素材找：有没有一个日期/一家公司/一本书？没有就**向用户要一个**，或用"话说 + 一个公认的历史场景"兜底 |
| 缺反转 | 只有结论没有意外 | 问："一个聪明的普通人会怎么看这件事？"把他写成靶子 |
| 缺机制 | 知道"其实不是 X"但说不出"那是什么" | 追问三个层次：制度层面？激励层面？约束条件层面？答不出 = 素材不够，向用户要 |
| 缺金句 | 道理说清了但记不住 | 进 Stage 2 挖；挖不出就造词 |
| 缺人味 | 全篇第三人称、像说明书 | 把用户自己的经历/观察放进去；加一处认怂或自黑 |

---

## 四、一念判定（必做）

把全部素材压成一句话，**主语是读者卡里那个具体的人**：

> **我想让<他>相信：__________。**

- 压不成一句 → 素材太散，必须砍到只剩一个核，或拆成两篇。
- 压出来是一句废话（"学习很重要"）→ 核不够反，回到第 2 步。
- 压出来是一句**<他>会反驳的话** → 对了，这就是罗胖体的核。
- 压出来的话换一批读者也完全成立 → 对象感丢失，回读者卡重校（好的一念判定通常**只**对这批读者成立）。

**素材与读者的对齐检查**：逐条过素材卡，标出哪些证据"读者世界里也有"。开场锚、举例、类比优先用读者世界里存在的——他看到"和我一样的人"才会读下去。

---

## 五、输出格式（素材卡表）

```markdown
## 一念判定
我想让读者相信：<一句话，必须反常识>

## 体裁
短稿 / 长稿（理由：…）

## 素材卡
| # | 类型 | 内容摘要 | 它证明什么 | 拟用位置 |
|---|------|---------|-----------|---------|
| 1 | 书/文章锚 | 《…》里说… | 大众以为 A | ①锚 |
| 2 | 反常识点 | … | 其实是 B | ③转 |
| 3 | 引语锚 | 某某说："…" | 机制是 C | ③转 / ④收 |
| … | | | | |

## 缺口
- 缺：<什么> → 已向用户索取 / 用 <方案> 兜底
```

**注意**：本阶段不写句子，只做 inventory。过早进入措辞会污染判断。
