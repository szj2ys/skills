# 结构标注范本

素材出处为罗振宇公开节目，本文件只保留**结构标注所需的最小引文**（首尾句 + 拆解），不做全文转载。
写作时模仿的是结构，不是复述这些句子。

## 一、完整短稿范本（2 篇）

### 1. 语音2018-09-26《让数据跟着你跑》——四拍最标准

> 1. 昨天，我在《李翔知识内参》里看到，日本家居行业巨头尼达利有一个规定：正在卖的产品，每年都必须更新掉 70%。那更新哪 70% 呢？答案是，卖得最好的产品先更新掉。
>
> 2. 这个做法听起来很奇怪。难道不应该是把卖得不好的产品先更新掉吗？为什么反其道而行之呢？你琢磨琢磨它的道理哈。
>
> 3. 卖得好的产品，被模仿得也快，为了保持商品的特色，所以要先更新掉。还有，越是卖得好的，就越时髦，顾客对于时髦的东西，热情来得快，去得更快，所以要先更新掉。还有，越是卖得好的，产品本身的创新速度也越快。赶紧去找下一代的货，而不是躺在老产品上享受红利，所以要先更新掉。
>
> 4. 你看，过去我们总是主张，做经营应该跟着数据决策。但是，跟着数据跑是一种策略，让数据跟着你跑，其实是一种更有效的策略。

**拆解**：①来源锚（昨天+书名+公司名+反常数字）②替读者说出常识异议 ③三重"所以要先更新掉"排比给机制 ④对照式重定义金句收。

---

### 2. 语音2018-07-19《想要意外之喜，请接受现状》——借他人金句收

> 1. 话说，在电影或者电视的拍摄现场，经常会遇到一种情况：一个镜头明明拍得很满意了，可是导演还是要说，来，再拍一条。这一条往往称之为"保一条"。哎，上一条很满意了，为啥还要保一条呢？
>
> 2. 有一位导演跟我说，这不是为了安全，不是真的担心声音画面的故障，其实是导演和演员的一个心理游戏。
>
> 3. 说上一条可以了，这是告诉演员，你已经有保底的了，可以自由发挥了。……其实，绝大部分情况下，导演说保一条，并不是真对上一条很满意，对此，演员心里也清楚得很。
>
> 4. 所以，在片场，当导演说保一条的时候，大家是有一种放下包袱轻装前进的默契的。最后这位导演跟我说了一句金句，他说："想有意外之喜，请先接受现状。"

**拆解**：①场景锚+反常细节设问 ②"有一位导演跟我说"引入机制 ③心理游戏拆解（中间段略）④金句所有权让渡给"一位导演"，自己只做转述者——无能人设的标准操作。

## 二、结构摘录（首尾句 + 拆解）

### 3. 语音2018-10-20《先见之明的前提》——历史场景锚
- **首**：「话说巴黎和会开到最后，在对合约做表决的那一天，法国的福煦元帅突然临时要求发言。」
- **转**：「但是，如果回到历史现场，福煦是有名的固执己见……所以他这段发言当然就没有受到应有的重视。」
- **尾**：「你看，每个人都可能有先见之明，但是如果你给同时代人的印象配不上这份重视，那你再正确的意见，也只能是让自己的良心好过一点。」
- **学**：①"话说+具体日期"把听众拽进现场 ②"但是回到历史现场"从事后视角翻回当时视角 ③金句把"意见正确"与"被重视的资格"挂钩。

### 4. 语音2018-12-23《为什么是波罗？》——造词收口
- **首**：「最近我和人聊起来，什么才是人类历史上最伟大的发明呢？有一个有趣的回答是，轴承……」
- **转**：「但是你发现没有？轴承的特点是这两者的特性都有……」
- **尾**：「……我们就称之为"轴承时刻"吧：能让人在沉迷和断开之间能自如切换，那才是最好的游戏啊。」
- **学**：现场造词"轴承时刻"——把物理隐喻迁移到产品哲学，造词法的教科书。

### 5. 语音2019-11-28《哪两句话坚决不能说？》——引书 + 自我承诺收
- **首**：「昨天我说到的那本书，松浦弥太郎的《100 个基本》，里面说到这么一段话……」（随后大段照读原文）
- **转**：「道理很简单，因为这两句话招不来任何同情和帮助，它只传达了一层意思……」
- **尾**：「对，在有限的时间和金钱内推进事物的前进，永远是我们自己的责任，永远是我们这些做事的人的宿命。」
- **学**：①"昨天我说的那本书"连载宇宙回调 ②大段原文照读=权威外包 ③落到"我今后也不说了"的个人承诺 ④"宿命"式升华收。

### 6. 语音2014.05.09《成长》——早年散文体（无编号）
- **首**：「有好几次哈，一堆人入住宾馆……几乎每个人都对自己身份证上的那张照片不满意」
- **转**：「其实细想想哈，这是一桩冤案……就是因为你当时就那么难看、土气和傻冒。」
- **尾**：「所以啊，身份证上的丑，其实印证了我们的成长而已啊。」
- **学**：无编号但骨架完全一致：场景锚→常识→"其实这是一桩冤案"→重定义金句。早年助词密度更高（哈/啊/呢/嘛）。

## 四、反面教材：哪些写法不像罗胖

| ❌ 不像 | 为什么 | ✅ 改成 |
|---|---|---|
| 「随着时代的发展，终身学习已成为…」 | 抽象开头，无具象锚 | 「昨天一位做游戏的朋友跟我讲…」 |
| 「综上所述，我们要…」 | 罗胖从不 recap | 删掉，直接给金句 |
| 「根据某某教授的研究表明…」 | 学术引用体 | 「我最近读到一本书，作者说…」 |
| 「我认为 / 我坚信…」 | 自居权威 | 「书里的说法让我大吃一惊…」 |
| 「罗胖曰：……」 | 全语料 0 次，后人误传 | 删掉 |
| 一篇讲三个观点 | 违反一念贯穿 | 拆成三篇 |
