# Reply Templates

Copy-paste scaffolds. Replace `[BRACKETS]` with the user's real story. Keep ≤ 280 characters where possible. Every reply must end with a **real question or counter-point** — never "nice post" / "great".

## Scenario templates

**Target posted a failure / throttle**
> I hit the same wall: [YOUR FAILURE STORY]. Lost [X]. Glad you say it out loud instead of hiding it. What finally unblocked you?

**Target posted revenue / data**
> Real numbers beat theory. Q: with [THEIR METRIC], is [SPECIFIC DRIVER] where the lift came from, or something else?

**Target posted a counterintuitive take**
> Partly agree. [YOUR NUANCE / COUNTER-POINT]. The risk is [X]. Curious where you'd draw the line.

**Target posted build-in-public**
> Same stage here: [YOUR BUILD STORY]. The lesson that stuck: [ONE LINE]. What's the one thing you'd tell past-you?

**First-hour universal template** (when unsure)
> [One sentence: this landed]. [One sentence: why]. [One real question]?

## How to tie to a true story
Generic compliments get ignored. Specific, vulnerable, or contrarian replies get seen. Before writing replies, collect **2–3 real experiences** from the user and reuse them as hooks. Examples collected in the origin session (replace with the user's own):

- **Zero-user product**: built an image tool for months, obsessed over the model, shipped with zero users.
- **Pre-launch throttle**: an auto-poster got the account restricted right before launch — automation risk is real.
- **AGENTS.md boundary rule**: "the model only judges, code does the deterministic work" / "an agent needs boundaries, not just autonomy."
- **Crossing the chasm**: built for geeks while real paying users = zero; the mismatch wasted two years.

## Quality bar
- ✅ Names a specific shared experience
- ✅ Adds a question or a counter-point
- ✅ Under ~280 chars (fits natively)
- ❌ "Great post", "Nice", "Love this"
- ❌ Pure praise with no hook
- ❌ A link with no context
